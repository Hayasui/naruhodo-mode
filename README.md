# turnabout-mode

本仓库是一个用研工作里的创造性思考技能。输入是一个生成性的任务（做假设、定研究问题、搭框架、设计问卷骨架、定分析出发点、写报告结论）。输出是一份候选清单，含靶、候选、每个候选的杀死条件，以及被砍掉的候选与理由。它给设计测试材料与写研究报告的人用。

说一句「异议！」就把这个技能叫起来。技能在动手之前插一轮分叉与淘汰。先把靶立出来，再摆出四个到七个互相分得开的候选，每个配一条杀死条件。最后把整块交回给人挑，收敛由人做。

它横在本工作流之外，不占任何一环。既有链条的任何一环动手前都能用。分叉出的候选随后交给对应的那一环去做，本技能不替它们做事。

```
定内容空间 → 写中文定稿 → 本地化英文 → Excel 留档
MECE-tool     adaptor      sc-to-en     md-to-research-xlsx

收数据 → 算读数 → 写成报告
dataset_cleaner → researcher-ready-report
```

用法从 `SKILL.md` 入手，操作细则与正反例在 `references/` 下。
