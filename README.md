# naruhodo-mode

本仓库是一个用研工作里的创造性思考技能。名字取自《逆转裁判》的主角成步堂龙一，他的姓读作 Naruhodō，与「なるほど」（原来如此）同音。输入是一个生成性的任务（做假设、定研究问题、搭框架、设计问卷骨架、定分析出发点、写报告结论）。输出是一份质证记录，含证词、主张、每条主张能被什么推翻、你对每条主张的判断，以及没提上庭的主张与理由。它给设计测试材料与写研究报告的人用。

说一句「异议！」就把这个技能叫起来，「Objection!」「把思维逆转过来」也一样。技能在动手之前插一轮交叉质证。先锁定这次要推翻的那句话。再提出四条到七条互相分得开的主张，每条配一条反证，并逐条写明你自己的判断。最后整份交回给人判决，判决权不留在技能这一侧。

它横在本工作流之外，不占任何一环。既有链条的任何一环动手前都能用。分叉出的候选随后交给对应的那一环去做，本技能不替它们做事。

```
定内容空间 → 写中文定稿 → 本地化英文 → Excel 留档
MECE-tool     adaptor      sc-to-en     md-to-research-xlsx

收数据 → 算读数 → 写成报告
dataset_cleaner → researcher-ready-report
```

用法从 `SKILL.md` 入手，操作细则与正反例在 `references/` 下。

远端仓库在 [naruhodo-mode](https://github.com/Hayasui/naruhodo-mode)，改动按惯例 commit 后推送。
